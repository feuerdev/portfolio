Projects

keep-mcp: A Python MCP server that lets AI agents search, read and edit Google Keep notes and checklists. It connects through gkeepapi and limits edits to notes labelled keep-mcp by default.

feuer.io: My eternal pet project since 2018. A multiplayer browser strategy game with procedural hex maps and A* pathfinding.

It has followed me from plain browser code to React, through Next.js and back to Vite, and from a VPS with Docker and Jenkins to Vercel and Render. I've used it to try shared-code monorepos, different authentication systems and state management approaches. It's still a work in progress.

YouTube sponsor detector: A browser extension that finds sponsored segments in captions using MobileBERT and Transformers.js, then skips them. Classification runs locally. It's a prototype: segment boundaries and caption handling still need work.

Split keyboards: Ergonomic keyboards for tinkerers. I assembled a Scylla from Bastard Keyboards and learned the Colemak-DH layout. I customise its QMK keymap with home-row modifiers, layers and combos, and maintain a ZMK config for my Totem. Photos of the assembly and finished keyboard.

Swift raytracer: A raytracer I wrote in 2021, drawing directly into a pixel buffer. It handles sphere intersections, lighting, shadows and recursive reflections. The iOS app lets you edit the scene. The repository has demos.

Big Pond: An iOS app for discovering marine life in a given area. I built it after moving to Taiwan and wondering what was in the water. Written with MapKit, VIPER and Grand Central Dispatch.

Earlier contract work includes Python development for a tire testing rig: command queues, UI separation and simulation performance.
